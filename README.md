# Housing_Market
This project explores the growing affordability crisis in the Texas housing market using a full ETL pipeline and Power BI visualizations.

Using Python, I extracted and parsed data from the U.S. Census API (median income, population, demographics) and Zillow (average home values). The data was then structured and stored in Snowflake using warehouses, databases, and schemas, before being modeled and visualized in Power BI.

The analysis reveals a widening gap between income growth and housing prices—highlighting affordability challenges across major Texas metro areas. Cities like Lubbock and Beaumont remain exceptions, with more accessible home values and Price-to-Income Ratios (PIR) within a sustainable range.

This project not only strengthened my ETL and data modeling skills but also shed light on the real-world impact of economic pressures on homeownership. Future phases will explore demographic wealth gaps and predictive modeling.
